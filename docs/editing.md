# 打开、修改与再次导出

HTML 是可执行工程，MP4 是已固定的播放结果。先在 HTML 中确认修改，再导出新 MP4

## 打开 HTML

1. 解压整个工程，进入**真正包含 `index.html` 的文件夹**
2. 在该目录打开 PowerShell 或终端
3. 运行 `python -m http.server 8000`
4. 浏览器访问 `http://127.0.0.1:8000/index.html`
5. 保持终端开启，关闭服务后网页可能无法继续读取素材

若解压后出现两层同名文件夹，进入内层再运行服务；也可在网址加入对应子目录

直接双击 HTML 可能因浏览器本地文件限制而无法读取 JSON 和音频。本机 `127.0.0.1` 地址不能直接当作给别人使用的分享链接

## 修改哪个文件

下面是本技能 starter 的职责，实际项目可能增加文件，应先查看入口及绘图代码的真实引用

| 要修改什么 | 通常修改哪里 |
|---|---|
| 段落内容、目的、事件、时长 | `film.json`，再编译 `timeline.json` |
| 图形、对象动作与镜头运动 | `scenes.js` |
| 通用绘图组件 | `components.js` |
| 共用颜色、字号、布局参数 | `style.json`，部分视觉也可能写在绘图代码中 |
| 页面、字体入口、播放控制 | `index.html`、`runtime.js` |
| 音乐或旁白 | 项目 `audio` 中的文件及 `film.json` 音轨引用 |
| 讲稿说明 | `script.md`，仅改此文档不会自动改画面 |

既有 `dataflow-film` 项目的主字幕读取 `timeline.json`，标题默认读取 `full-plan.json`；这是该片的实现，不是全部项目的统一规则。直接改时间轴后要同步时序源，防止下次编译覆盖

保存时选择 UTF-8，保留 JSON 的引号、逗号与括号。修改时长需要重排动作、阅读时间和音轨

## 让 Codex 帮你改

```text
请读取这份完整HTML工程
把第12秒开始的主字幕改成：[新内容]
这一段多停留2秒，后续动作和音乐随之对齐
沿用已认可字体、配色和运动规则，不生成环境场景
先提供连续HTML预览，我确认后再导出MP4
同步更新实际运行文件、文稿和受影响的采用记录
```

工程是代码源码，当前没有拖拽式视频编辑面板

## 再次导出

- 修改文字或动作：重新预览、更新受影响记录，再渲染候选片并复审
- 仅修改 BGM：可保留已有视频流，重新编码音频与封装，但仍需核对实际音轨长度及新候选的检查和审片记录
- 风格或素材已锁定：保留原版本，按既有授权与版本流程更新，不能删锁伪装首次制作
- 换曲不能用相似音乐冒充指定原曲，报告说明实际来源、区间、循环与淡化方式

具体执行命令见[制作命令](../references/production.md)，不建议为了导出而跳过七项检查或直接把候选片重命名为正式片

## 常见问题

| 表现 | 先检查什么 |
|---|---|
| 404 / File not found | 服务目录是否真的有 `index.html`，网址子路径是否正确 |
| 拒绝连接 | 本地服务是否仍运行、端口是否一致 |
| 中文乱码 | 文件保存编码与页面编码是否为 UTF-8；文稿可提供明确编码的 HTML 阅读页 |
| 修改后没变化 | 是否改了实际读取的文件，刷新或 Ctrl+F5；只改文稿不会改图像 |
| 动画加载失败 | 脚本、JSON、字体、vendor 与音频是否完整，查看浏览器错误 |
| 音乐出现“抖音”等片尾提示 | 参考音轨是否带平台片尾，排除对应区间后重接纯音乐 |
| 后半段没声音 | 核对实际音轨长度，不能只看 MP4 总时长或旧报告字段 |

音轨修订后，检查真实采样长度、封装后音轨覆盖与片尾，完整试听循环接缝。未实际试听时如实标注，不能用数值一致替代听感通过
