## 使用GitHub Desktop

1 选择 File / Add local repository，把当前发布目录加入
2 点击 Publish repository，仓库名称使用 story-motion-studio
3 选择公开或私有，确认后发布到 yangmuye520-dotcom
4 发布后，在干净目录或另一台电脑测试README中的安装指令

公开仓库方便别人直接下载安装；私有仓库要求相应访问权限，README的匿名远程下载命令不适用于私有仓库
