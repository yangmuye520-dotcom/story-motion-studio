# 样例库

examples/index.html 展示三套已认可画面风格的无声预览、源码和 sample.json；catalog.json是当前状态来源。新片不继承历史音乐、采用记录或生产检查结论

运行样例HTML需要从技能根目录启动HTTP服务。点开单个样例时，它仍能找到本目录的字体、配置和必要vendor代码

新增样例先在外部项目目录完成，用 scripts/samples.py add 入库候选，用approve/reject记录真实决定；命令详见 --help。用户未要求长期保存时，候选和失败工程留在项目目录，安装包只保留可复用认可样例

原参考视频、历史音轨、逐帧检查图片、旧候选、交接文档和重复素材备份不随技能分发。样例风格方向获认可不等于新片验收，重做新片仍需七项实际贡献
