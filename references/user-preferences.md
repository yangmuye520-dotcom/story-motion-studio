# 当前用户约定

这些是本地用户的明确选择，保留适用范围，不把某一条成片的要求升级成所有视频的统一规范。后续用户明确修改时同步对应条目

## 画面限制

原用户要求“不要生成任何的场景”，当前工作流沿用这一明确限制

采用独立对象、按键、箭头、粒子、图表和文字解释内容。三维用于独立物件或结构，不新造游戏靶场、地图、房间、街道等环境与布景，也不换生成技术继续搭同类环境

已认可风格不覆盖后来这项限制。故事用问题、动作和结果推进，无需生成环境场景


## 默认制作选择

中文屏幕叙述、无配音、免费工具、16:9、1920×1080、30fps。用户本片明确要求优先，时长按内容、动作与阅读预算决定

不要把某条视频的150秒、无句号、某段BGM或某个主题当作全局固定要求。指定音乐按当前素材与使用依据处理，不自动继承样片音轨
