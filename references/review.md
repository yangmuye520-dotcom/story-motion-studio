# 以真实问题检查

| 症状 | 核验 | 修正源头 |
|---|---|---|
| 看不懂 | 零背景能否说出问题、变化、结论 | 缩小主题、用同一具体例子、补因果 |
| 图片轮播 | 镜内前中后/连续段是否有新状态 | 重写对象动作和承接，而非只加缩放/粒子 |
| 文案单薄 | 背景、动机、机制、应用、结果、边界 | 补对应内容并重新估时 |
| 字太密 | 目标观看尺寸与正常速度 | 精简、拆段、增时；辅助小字不承载关键事实 |
| 风格波动 | 已认可样片、tokens、组件、哈希 | 回到统一系统；用户改风格另建版本 |
| BGM不对 | 来源、实际音轨、处理、时长、听感/峰值 | 修素材混音，不以相似曲冒充 |
| skills说得不实 | 读方法/改源码/执行命令是否分开 | 改execution，不以七项打勾替代证据 |

技术检查包含素材/风格一致、字体、浏览器错、外边界、乱序一致、MP4完整解码和源码SHA。不同图像只证明图像变化，语义/流畅需对照分镜。

每镜前中后和转场抽样，必要时从最终MP4取连续帧；控制台无错不能替代。报告分工具、实际抽样、完整观看/试听、用户认可，未做写未做。本版完整成片按video-shotcraft要求独立评审，短样无需默认开代理，完整成片按七包契约必须独立终检，不预设审查结论。

交付真实MP4和可改工程、本地素材/许可、来源、文稿分镜、时间轴、执行记录、素材历史、风格依据和报告。发给别人用MP4；localhost只本机。未经授权不远程上传。工具通过不等于审美通过。
